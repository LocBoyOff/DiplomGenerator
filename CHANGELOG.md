# История изменений

## 2.0.0 — 12 октября 2026

### Возможности и интерфейс

- Обновлён интерфейс: светлое оформление, карточки настроек, прогресс, оценка оставшегося времени и журнал генерации.
- Два режима объединены в основном приложении: «Один диплом на строку (orig)» и «Команда — несколько участников».
- В режиме orig каждая непустая строка активного листа Excel создаёт один диплом; поля шаблона сопоставляются с колонками.
- В командном режиме отдельный диплом создаётся для каждого непустого участника из колонок `FullN1`, `FullN2` и далее. Общие поля берутся из строки команды; тренер — из первой непустой колонки `FullTr…`.
- Добавлена предварительная проверка данных без запуска Office.
- Сопоставление колонок и правила для пустых полей применяются в обоих режимах: остановить, пропустить диплом или заполнить значениями по умолчанию.
- Настройки и подробный журнал сохраняются в пользовательской папке приложения.

### Шаблон и текст

- При замене полей сохраняются шрифт, цвет, жирность, курсив и оформление текстовых фрагментов, включая поля, разбитые на несколько фрагментов. Подставленный текст наследует оформление начала поля.
- Поддерживается замена полей в текстовых блоках, группах и таблицах первого слайда.
- Длинный текст измеряется самим PowerPoint и уменьшается без автоматического переноса. Разные размеры шрифта уменьшаются пропорционально; ручные переносы и абзацы сохраняются.
- Уменьшение текста включено по умолчанию в обоих режимах и может быть отключено, чтобы использовать свойства шаблона.
- Даты Excel и поддерживаемые текстовые даты для полей `{DATE}` / `{ДАТА}` приводятся к формату `дд.мм.гггг`.

### Качество PDF

- Используется прямой экспорт PowerPoint в PDF с качеством для печати. Текст остаётся выделяемым, а векторные элементы сохраняются.
- После экспорта программа восстанавливает исходные пиксели PNG/JPEG-картинок из PPTX, устраняя сжатие с потерями, которое Office может применять к изображениям.
- Восстановление сохраняет размещение картинок, прозрачность и ресурсы шрифтов PDF. Оно работает в обоих режимах.
- Неоднозначные соответствия и неподдерживаемые изменения изображения, например изменения яркости или цвета, сохраняются в варианте Office; сведения записываются в журнал.

### Надёжность

- Улучшены сообщения о повреждённых и недоступных файлах, отсутствующих колонках, пустых полях и формулах без сохранённых результатов.
- Обрабатываются недопустимые символы и зарезервированные имена Windows; слишком длинные пути сопровождаются понятным сообщением.
- Существующие PDF не перезаписываются: совпадающие имена получают суффиксы `(2)`, `(3)` и далее.
- Экспорт Office выполняется в отдельном процессе с тайм-аутом. Остановка завершает только подтверждённый собственный процесс PowerPoint; ранее открытый PowerPoint сохраняется.
- Уже созданные PDF сохраняются после остановки или ошибки.

### Требования и ограничения

- Готовая сборка предназначена для Windows x64. Python для запуска EXE не нужен.
- Требуется установленный и активированный Microsoft PowerPoint с завершённой первоначальной настройкой Office. Microsoft Excel для чтения `.xlsx` не требуется.
- Обрабатывается только первый слайд шаблона `.pptx`.
- Необходимые шрифты должны быть установлены в Windows или доступны Office; отсутствующие шрифты PowerPoint может заменить.
- Восстановление картинок сохраняет качество исходника и не добавляет детализацию. Полученные PDF обычно занимают больше места.

### Проверки

- Пройдены 38 автоматических проверок Python и интеграционных проверок с установленным PowerPoint, включая оба режима, оформление текста, уменьшение длинных строк и восстановление изображений PDF.
