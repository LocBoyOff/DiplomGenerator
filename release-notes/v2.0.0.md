# Генератор дипломов 2.0.0

Новая версия объединяет оба способа генерации в одном приложении, сохраняет оформление текста из шаблона и устраняет потерю качества фоновых картинок при экспорте PowerPoint в PDF.

## Что изменилось

- **Обновлённый интерфейс.** Светлое оформление, карточки настроек, прогресс, оценка оставшегося времени и журнал.
- **Два режима.** В режиме «Один диплом на строку (orig)» каждая непустая строка Excel даёт один PDF. В режиме «Команда — несколько участников» каждый участник из колонок `FullN1`, `FullN2` и далее получает свой диплом с общими данными команды.
- **Проверка до генерации.** Можно проверить таблицу и сопоставление полей без запуска Office. Работают правила для пустых полей: остановить, пропустить диплом или заполнить значениями по умолчанию.
- **Сохранение оформления.** Шрифты, цвет, жирность и курсив сохраняются при подстановке, в том числе в группах и таблицах. Текст, вставленный вместо поля, наследует оформление его начала.
- **Длинный текст помещается в строку.** PowerPoint измеряет текст, а программа уменьшает размер шрифта без автоматического переноса. Ручные переносы и абзацы остаются. Опция включена по умолчанию в обоих режимах.
- **PDF с качеством исходных картинок.** После прямого экспорта программа восстанавливает оригинальные пиксели изображений из PPTX без потерь. Текст остаётся выделяемым; сохраняются векторные элементы, ресурсы шрифтов и размещение картинок.
- **Понятные ошибки и безопасная остановка.** Улучшена обработка путей, повреждённых файлов, пустых полей и формул без сохранённых результатов. Одинаковые имена файлов получают суффиксы; существующие PDF не перезаписываются. Отмена сохраняет готовые дипломы и не завершает ранее открытый PowerPoint.

## Как запустить

1. Скачайте `DiplomaGenerator.exe` из раздела **Assets** этого релиза и запустите его на Windows x64. Либо скачайте `DiplomaGenerator-v2.0.0-windows-x64.zip` и распакуйте архив: он содержит EXE, инструкцию, описание релиза и контрольные суммы. Устанавливать Python не нужно.
2. Убедитесь, что Microsoft PowerPoint установлен и активирован. Перед первым экспортом запустите PowerPoint вручную и завершите первоначальную настройку Office.
3. Выберите Excel `.xlsx`, шаблон `.pptx` и папку результата.
4. Выберите режим, настройте сопоставление полей и нажмите «Проверить данные».
5. Нажмите «Создать дипломы».

Microsoft Excel для чтения таблицы не требуется. Для формул нужны сохранённые результаты: если проверка сообщает об их отсутствии, пересчитайте и сохраните книгу в Excel.

Пользователям старой версии рекомендуется проверить сопоставление полей в новом приложении. Старый `config.json` из рабочей папки больше не используется; настройки и журнал сохраняются в пользовательской папке приложения.

## Ограничения

- Используется только первый слайд шаблона. Поля заменяются в текстовых блоках, группах и таблицах самого слайда; текст внутри изображений, диаграмм, SmartArt и образца слайда не заменяется.
- Шрифты шаблона должны быть установлены в Windows или доступны Office. Отсутствующий шрифт PowerPoint может заменить.
- Если текст не помещается даже при минимальном размере, программа сообщит о проблемном блоке; потребуется сократить текст или увеличить блок в шаблоне.
- Восстановление картинок сохраняет детализацию исходного изображения. Картинка с низким разрешением не станет более детальной.
- При неоднозначном сопоставлении или неподдерживаемых изменениях картинки, например изменениях яркости и цвета, сохраняется результат Office. Такие случаи записываются в журнал.
- PDF обычно становится больше из-за сохранения оригинальных пикселей картинок.

## Проверки

Пройдены 38 автоматических проверок Python и интеграционных проверок с установленным PowerPoint: оба режима, сохранение оформления, уменьшение длинного текста, группы, таблицы и восстановление качества изображений PDF.

Собранный Windows x64 EXE также прошёл самостоятельную проверку: создание интерфейса, экспорт одного диплома в режиме orig и двух в командном режиме, сохранение шрифтов, уменьшение длинного текста и точное совпадение пикселей фона с исходным PNG.
