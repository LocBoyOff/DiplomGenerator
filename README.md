# Генератор дипломов 2.0.0

Приложение для Windows: Excel + шаблон PowerPoint → персональные PDF.

## Готовая программа для Windows

Скачайте [DiplomaGenerator.exe](https://github.com/LocBoyOff/DiplomGenerator/releases/latest/download/DiplomaGenerator.exe) или архив с инструкцией из [последнего релиза](https://github.com/LocBoyOff/DiplomGenerator/releases/latest). EXE содержит Python и библиотеки; отдельно устанавливать Python не нужно. Поддерживается Windows x64. Microsoft PowerPoint должен быть установлен и активирован.

Изменения версии — в [описании релиза 2.0.0](https://github.com/LocBoyOff/DiplomGenerator/releases/tag/v2.0.0).

## Запуск из исходников

Нужны Python и установленный, активированный Microsoft PowerPoint. Excel как приложение для чтения таблиц не требуется. Перед первым экспортом запустите PowerPoint вручную и завершите первоначальную настройку Office.

```powershell
python -m pip install -r requirements.txt
python diploma_generator.py
```

## Два режима

**Один диплом на строку (orig).** Первая строка активного листа Excel содержит названия колонок. Каждая последующая непустая строка создаёт один диплом. В окне «Настроить поля» свяжите поля шаблона с колонками, например `{NAME}` → `ФИО`, `{CITY}` → `Город`. Имя файла — `ФИО.pdf`; если имя определить нельзя, используется номер строки.

**Команда — несколько участников.** Каждая строка содержит общие данные команды и колонки `FullN1`, `FullN2` и т.д. Каждый непустой участник получает отдельный диплом. `{NAME}` заполняется из соответствующей колонки участника; `{TRAINER}` — первым непустым значением `FullTr1`, `FullTr2` и т.д. Остальные поля сопоставляются с колонками. Название команды `TEAMNAME` или поле `{TEAM}` добавляется к имени PDF.

| FullN1 | FullN2 | FullTr1 | TEAMNAME | CITY |
| --- | --- | --- | --- | --- |
| Анна Иванова | Борис Петров | Ирина Смирнова | Орбита | Тюмень |

Эта строка создаст два диплома. Поддерживаются заголовки с фигурными скобками, например `{FullN1}`. Повторяющиеся заголовки необходимо переименовать.

## Порядок работы

1. Выберите `.xlsx`, шаблон `.pptx` и папку результата. Пути можно вставить вручную.
2. Выберите режим генерации.
3. Настройте сопоставление полей и значения по умолчанию. Автосопоставление предлагает известные названия; проверьте результат.
4. Выберите правило для пустых полей: остановить, пропустить диплом или заполнить заданными значениями. В последнем случае незаполненное значение по умолчанию считается ошибкой.
5. При необходимости включите «Уменьшать длинный текст без переноса строк» и распределение PDF по папкам.
6. Нажмите «Проверить данные». Проверка показывает количество дипломов, предупреждения и первые имена; Office при этом не запускается.
7. Нажмите «Создать дипломы».

## Шаблон и результат

Используется **первый слайд**. Поля вида `{NAME}`, `{DATE}`, `{CITY}` можно размещать в обычных текстовых блоках, группах и таблицах. Имена полей чувствительны к регистру. Текст внутри изображения, диаграммы, SmartArt или макета/образца слайда не заменяется: перенесите такие поля в текстовый блок самого слайда.

Замена сохраняет шрифт, цвет, жирность, курсив и другие свойства текстовых фрагментов, даже если поле разбито на несколько фрагментов. Подставленный текст наследует оформление начала поля.

Опция «Уменьшать длинный текст без переноса строк» включена по умолчанию в обоих режимах. Перед экспортом программа измеряет текст самим PowerPoint и уменьшает только размер шрифта, если строка или высота блока переполняется. Разные размеры в одном блоке уменьшаются пропорционально; семейства шрифтов и начертания остаются прежними. Автоматический перенос отключается; заданные в шаблоне абзацы и ручные разрывы строк сохраняются. Для ячеек таблиц используется отдельный расчёт, поскольку PowerPoint запрещает менять их AutoSize и WordWrap через COM.

Если опция выключена, свойства автоподбора и переноса остаются такими, как в шаблоне. Если текст нельзя уместить даже минимальным размером, приложение укажет проблемный блок. Нужные шрифты должны быть установлены в Windows или доступны Office: отсутствующий шрифт PowerPoint может заменить.

PowerPoint экспортирует PDF с качеством для печати. Затем программа восстанавливает исходные PNG/JPEG-картинки из PPTX в ресурсах PDF с компрессией без потерь: Office способен перекодировать даже PNG в JPEG независимо от отключённого сжатия картинок. Текст, встроенные шрифты, векторные элементы, прозрачность, расположение картинок и размер страницы сохраняются. Размер страницы соответствует слайду. Одинаковые имена получают суффиксы `(2)`, `(3)` — существующие PDF не перезаписываются. Недопустимые символы и зарезервированные имена Windows заменяются. Даты Excel и распространённые текстовые форматы дат для `{DATE}`/`{ДАТА}` приводятся к `дд.мм.гггг`.

## Ошибки и остановка

- Для недоступных, повреждённых файлов, отсутствующих колонок и пустых полей показываются объяснения со строкой Excel.
- Формулы должны иметь сохранённые результаты: откройте, пересчитайте и сохраните книгу в Excel, если приложение просит это сделать.
- Для слишком длинного пути выберите короткую папку, например `D:\Дипломы`. Сетевые диски должны быть доступны, а папка — разрешать запись.
- Экспорт выполняется в отдельном процессе. Остановка и тайм-аут не завершают все процессы PowerPoint: приложение закрывает свою презентацию и завершает только подтверждённый собственный процесс Office. Если PowerPoint уже был запущен, его процесс сохраняется.
- Уже созданные PDF сохраняются после остановки или ошибки. Повторный запуск создаёт новые файлы с суффиксами.
- Один экспорт ограничен 90 секундами. Диалоги активации Office или заблокированный шаблон могут потребовать вмешательства пользователя.

Настройки и подробный журнал с трассировками хранятся в `%LOCALAPPDATA%\DiplomaGenerator`. Журнал ограничен по размеру и доступен по кнопке в приложении. Старый `config.json` в рабочей папке больше не используется.

## Структура проекта

- `diploma_generator.py` — интерфейс и запуск приложения.
- `diploma_core.py` — чтение Excel, оба режима генерации, подстановка текста и экспорт Office.
- `pdf_quality.py` — сохранение исходного качества картинок в PDF.
- `app_version.py` — номер версии приложения.
- `assets/` — иконка и сведения о версии EXE.
- `requirements.txt` — зависимости для запуска из исходников.
- `requirements-build.txt`, `DiplomaGenerator.spec`, `build_release.ps1` — сборка Windows EXE.

## Качество фоновых картинок

Восстановление картинок работает автоматически в обоих режимах. Оно не превращает весь слайд в фотографию: текст остаётся выделяемым, а картинки возвращаются с исходными пикселями и прозрачностью. PDF обычно становится больше. Если оригинал имеет низкое разрешение, новые детали не появляются — сохраняется доступное качество исходника.

Картинки сопоставляются по пропорциям и содержимому. Неоднозначные соответствия, изображения с изменением яркости/цвета и другие неподдерживаемые случаи сохраняются в варианте Office; сообщение об этом попадает в журнал. Исходные файлы и настройки PowerPoint не изменяются.

## Сборка EXE

Сборка выполняется на Windows x64 с Python 3.14. Зависимости сборки зафиксированы в `requirements-build.txt`; состав EXE описан в `DiplomaGenerator.spec`.

```powershell
.\build_release.ps1
```

Результат — `dist\DiplomaGenerator.exe`. Рабочие файлы, личные дипломы, настройки и журналы в EXE не включаются.
